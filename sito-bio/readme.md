# 🚀 Website Template Setup Guide

Welcome to this website template! Follow these step-by-step instructions to download the template, customize it with your own information, and deploy it live on the web for free. You can see an example -> awsaf-website.onrender.com

---

## 🛠️ Step 1: Download the Template Files
1. Go to my GitHub repository where the template files are located.
2. Click the green **Code** button at the top right.
3. Select **Download ZIP**.
4. Once downloaded, extract the ZIP file and put all the contents into a new folder on your **Desktop**. Name this folder whatever you like (e.g., `my-website`).

---

## 📸 Step 2: Add Your Profile Image
Before uploading anything, you need to add your personal photo to the project:
1. Open your website folder on your Desktop.
2. Look for the folder named `static`.
3. Move your preferred image/photo into this `static` folder. 
*(Note: Remember the exact name of your image file, for example: `my-photo.jpg`)*.

---

## ✏️ Step 3: Personalize Your Information
Before publishing, you must replace the placeholder text with your actual details:
1. Open the code files (like `app.py` or configuration files) using a text editor (e.g., Notepad, VS Code).
2. Look for the placeholder text such as **"Your name"**, **"link"**, **"description"**, etc.
3. Replace them with your **Name**, **Links**, **Description**, and update the image path to point to your new photo inside the `static` folder.
4. Save all the files.

---

## 📤 Step 4: Upload the Folder to Your GitHub
To host your website, you need to put it on your own GitHub account.

1. Go to [GitHub](https://github.com) and log in (or create an account).
2. Click the **"+"** icon in the top right corner and select **New repository**.
3. Give your repository a name, set it to **Public**, and click **Create repository**.
4. On the next screen, click the link that says **"uploading an existing file"**.
5. Drag and drop **all the files and folders** (including the `static` folder) from your Desktop folder directly into the GitHub upload box.
6. Scroll down to the bottom and click the green **Commit changes** button.

---

## 🌐 Step 5: Deploy Live on Render
We will use Render to put your website online. **Important: Sign in with your GitHub account.**

1. Go to [Render](https://render.com) and click **Sign Up** or **Log In**.
2. Choose **Sign in with GitHub** (use the exact same account you used in Step 4).
3. Once logged in, click the **New +** button in the dashboard and select **Web Service** (or **Static Site** depending on your project type).
4. Select **Connect a repository**. You will see a list of your GitHub projects.
5. Find the repository you created in Step 4 and click **Connect**.
6. Leave the settings as default, scroll down, and click **Deploy Web Service / Deploy Site**.

🎉 **That's it!** Render will take a minute to build your site, and then it will provide you with a live URL (e.g., `://onrender.com`) that you can share with anyone!
